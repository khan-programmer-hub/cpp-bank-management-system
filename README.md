# 🏦 C++ Bank Management System

A console-based Bank Management System built using Object-Oriented Programming (OOP) in C++.  
This project simulates real-world banking operations with a simple menu-driven interface.

---

## ✨ Features

- Create bank accounts
- Deposit money into account
- Withdraw money securely
- Check account details
- Basic account validation
- Array-based account storage

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Arrays
- Console Application

---

## 📌 Project Purpose

This project was built to strengthen:
- OOP concepts
- Problem-solving skills
- Real-world system design
- C++ programming fundamentals
